# CE Money Tracker Pro (Telegram Mini App — ครบทุกเฟส 1–4)

แอปบันทึกรายรับ-รายจ่าย โอนระหว่างวอลเล็ท รองรับทั้ง **บาท (THB)** และ **USDT** แนบสลิปแบบส่วนตัว ตั้งงบประมาณ รายการประจำ ล็อกรหัส PIN และบอทแจ้งเตือนผ่าน Telegram

## สถานะการพัฒนา (ครบสมบูรณ์ทุกเฟส)
- ✅ **เฟส 1**: ดีไซน์ Dark Luxury Fintech + Glassmorphism, เมนูล่าง 5 ช่อง, วอลเล็ท+โลโก้ตาม `logos.json`, หมวดหมู่เริ่มต้นครบชุด, บันทึกรายรับ/รายจ่าย/แนบสลิป (ดูเต็มจอ), งบประมาณ, หน้าบัญชี
- ✅ **เฟส 2**: โอนระหว่างวอลเล็ท (พร้อมค่าธรรมเนียมและโอนข้ามสกุลเงิน), รองรับ **USDT** (ทศนิยมสูงสุด 4 ตำแหน่ง) + ดึง/ตั้งเรท THB/USDT, ระบบ **แท็ก (#Tags)** พร้อมกรองและดูรายงานตามแท็ก
- ✅ **เฟส 3**: **รายการประจำ** (รายวัน/สัปดาห์/เดือน/ปี ทำงานอัตโนมัติ), **รายงานและส่งออกขั้นสูง** (กรองช่วงวันที่/วอลเล็ท/แท็ก ส่งออก CSV & JSON), **รหัส PIN 4–6 หลัก** (เข้ารหัส Scrypt + จำกัดการเดาสุ่ม), **ถังขยะกู้คืนข้อมูล + ประวัติการแก้ไข (Audit Log)**
- ✅ **เฟส 4**: **บอทแจ้งเตือน Telegram** (ใช้ `BOT_TOKEN` จาก Environment Variable เท่านั้น) แจ้งเตือนงบประมาณอัตโนมัติ แจ้งเตือนรายการประจำ สรุปรายวัน และรองรับคำสั่งด่วนในแชท (`/summary`, `/in`, `/out`)

## ความปลอดภัยและการรักษาข้อมูลผู้ใช้
- ตรวจลายเซ็น HMAC-SHA256 ของ `Telegram.WebApp.initData` ที่ฝั่ง Backend ทุกครั้ง
- แยกข้อมูลและสลิปตามรหัสผู้ใช้ (`user_id`) ไม่ปะปนกับผู้ใช้อื่น
- ไม่มี API Key หรือ Secret อยู่ในโค้ด Frontend อ่านจาก Environment Variables เท่านั้น
- ไฟล์สลิปเก็บแบบ Private นอก Static Root เปิดดูได้เฉพาะเจ้าของบัญชี
- ปิดบังเลขบัญชีและ Token อัตโนมัติใน Log และเก็บเลขบัญชีเฉพาะ 4 ตัวท้าย
- การลบทั้งหมดเป็น Soft Delete กู้คืนได้เสมอจากถังขยะ และการอัปเดตฐานข้อมูลเป็นแบบเพิ่มคอลัมน์เท่านั้น ไม่ลบข้อมูลผู้ใช้

## วิธีรันและ Deploy

### 1. รันด้วย Node.js (22+)
```bash
cp .env.example .env
# ตั้งค่า BOT_TOKEN และ SESSION_SECRET ใน .env

npm install
npm run build
npm start        # Production server ที่พอร์ต 4173
```

### 2. รันด้วย Docker
```bash
docker build -t ce-money-tracker-pro .
docker run -d \
  -p 4173:4173 \
  -e BOT_TOKEN="ใส่_BOT_TOKEN_จาก_BotFather" \
  -e BOT_POLLING="true" \
  -e SESSION_SECRET="ใส่_SECRET_สุ่มยาวอย่างน้อย_32_ตัวอักษร" \
  -v ce_money_data:/app/data \
  --name ce-money-tracker \
  ce-money-tracker-pro
```
